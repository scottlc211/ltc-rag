# 销售计划：年度→月度→部门→员工四级分解

> 归属：`crm-data` · docKey：`crm/data/sales-plan` · 证据：`t_sales_plan` / `t_sales_plan_monthly` / `t_sales_dept_plan` / `t_sales_employee_plan` / `t_sales_commission*` DDL + management/sales（7 控制器 / 53 接口）

## 一句话

计划是**四级分解**：公司年度总盘 → 月度切分 → 部门认领 → 员工到人。每一级都要满足"分解额 ≤ 上级额度"，否则分解不进去。

## 四级结构

```
t_sales_plan（年度总盘，按年）
   │  COMPANY_PLAN_TOTAL / _DIRECT / _AGENT
   ↓ 按月切
t_sales_plan_monthly（月度分解）
   ↓ 部门认领
t_sales_dept_plan（部门计划）
   ↓ 员工认领
t_sales_employee_plan（员工计划）
```

每一级的三个金额都按**直营 / 代理商 / 合计**拆开——和业绩口径一致。

## 主表 `t_sales_plan`

| 字段 | 含义 | 单位 |
|---|---|---|
| `YEAR` | 年份 | |
| `COMPANY_PLAN_TOTAL` | 公司计划回款总额 | **万元** |
| `COMPANY_PLAN_DIRECT` / `COMPANY_PLAN_AGENT` | 直营 / 代理商 | **万元** |
| `DEPT_ALLOCATED_AMOUNT` | **已分解到部门的金额** | 万元 |
| `EMPLOYEE_ALLOCATED_AMOUNT` | **已分解到员工的金额** | 万元 |
| `PLAN_STATUS` | 1 已发布 / 2 已归档 | |

> `DEPT_ALLOCATED_AMOUNT` / `EMPLOYEE_ALLOCATED_AMOUNT` 是**冗余的"已用额度"**。分解时校验 `已分解 + 本次 ≤ 总盘`，超了就报错。排查"为什么加不上去"看这两个字段。

## 部门 / 员工计划表

两张表结构几乎一样：

| 字段 | 部门表 | 员工表 | 单位 |
|---|---|---|---|
| 主键 | `DEPT_PLAN_ID` | `EMPLOYEE_PLAN_ID` | |
| 计划总额 | `DEPT_PLAN_TOTAL` | `PLAN_TOTAL` | **万元** |
| 直营 | `DEPT_PLAN_DIRECT` | `PLAN_DIRECT` | 万元 |
| 代理商 | `DEPT_PLAN_AGENT` | `PLAN_AGENT` | 万元 |
| **手动上报已回款** | `MANUAL_REPORTED_TOTAL` | `MANUAL_REPORTED_TOTAL` | **元** ⚠️ |
| 直营 / 代理商上报 | `MANUAL_REPORTED_DIRECT` / `_AGENT` | 同 | 元 |

### ⚠️ 同一张表里两套单位

```
PLAN_TOTAL              decimal(22,6)  单位：万元
MANUAL_REPORTED_TOTAL   decimal(16,2)  单位：元
```

**这是全系统最容易算错 10000 倍的地方。** 算达成率必须先统一：

```
达成率 = (MANUAL_REPORTED_TOTAL / 10000) / PLAN_TOTAL × 100%
```

而且精度也不一样：计划 6 位小数，上报 2 位小数。

## 达成率的分母到底是什么

`t_sales_plan_monthly`（月度分解）是**关键中间层**：

- **年度达成率** → 分母 `t_sales_plan.COMPANY_PLAN_TOTAL`
- **月度达成率** → 分母 `t_sales_plan_monthly` 对应月份
- **部门/员工达成率** → 分母对应的 dept/employee 计划

> 之前一直标 ⚠️ 的"达成率分母"现在明确：**看哪个口径就用哪一级的计划**。年度看公司计划、月度看月度分解、个人看员工计划——三个数天然不同。

## 手动上报

`t_sales_plan_manual_report` + `_detail`：某些回款没走系统（线下收款、历史数据），由主管**手动上报**补进计划完成度，明细记录上报了哪些人。

这就是 `MANUAL_REPORTED_*` 的来源。**它和真实回款是两套数**，报表里要区分。

## 提成

| 表 | 作用 |
|---|---|
| `t_sales_commission` | 提成方案（`PLAN_NAME` + 有效期 `START_DATE`/`END_DATE` + `STATUS` 1启用/0停用） |
| `t_sales_commission_gradient` | 梯度（阶梯比例） |
| `t_sales_commission_incentive` | 提成激励明细 |

方案有**有效期**，同一时间只能有一个启用方案，跨期计算要按回款日期选方案。

## 常见问题

- **Q：计划分解不进去？** 上一级已分解额（`DEPT_ALLOCATED_AMOUNT` / `EMPLOYEE_ALLOCATED_AMOUNT`）加本次超额。
- **Q：达成率算出来大 10000 倍？** 分母计划是万元、分子上报是元，没换算。
- **Q：达成率和业绩报表对不上？** 计划看的是"回款完成"，业绩看的是"关账快照"，口径不同。
- **Q：员工看到的计划和主管看到的不一样？** 各级看各自那一级。
- **Q：提成按哪个方案算？** 按回款所属日期落在哪个方案的有效期内。
